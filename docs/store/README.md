## Capturing the real screenshots

> [!WARNING]
> Restoring the sample replaces the contents of the install used for the screenshots. Use a separate Android work profile, secondary user, or data-free test install. **Do not restore it into the real family vault.**

1. Install a build containing **Settings → Security → Temporary screenshots** in the separate test profile/install.
2. Complete first setup with a temporary PIN and temporary owner name.
3. Open **Settings → Storage & privacy → Restore backup**, choose `my-vault-sample-vault.mvbackup`, confirm the temporary PIN, and replace the empty test vault.
4. Open **Settings → Security**, tap **Allow screenshots for 5 minutes**, read the warning, and confirm the temporary PIN.
5. Capture, in order: **Home**, **Documents**, **Family**, and **Settings → Storage & privacy** (Backup & restore card visible). If the five-minute window expires, repeat step 4. Leaving the app or locking it ends the window early.
6. Keep the original, uncropped PNGs. Review them for notifications or other private information before sharing them, then replace the four files above using the same filenames.

## Short description

Offline-first encrypted family document vault for Indian IDs and certificates.

## Full description

My Vault is an offline-first Android document vault built for Indian family IDs and certificates. Store Aadhaar, PAN, passports, driving licences, SSLC/degree certificates, vehicle and property documents, and other important papers for each family member.

Documents can be added by multi-page ML Kit scanning or by choosing an image/PDF file. On-device OCR suggests Aadhaar, PAN and Driving Licence numbers for review before saving. Document pages and profile photos are encrypted on the device with AES-256-GCM using Android Keystore, and the vault is protected by a PIN with optional biometric unlock.

My Vault also includes English and Malayalam, family profiles, personal and shared document groups, search and favourites, clean profile-card sharing, and portable `.mvbackup` backup files. Each backup can use a PBKDF2/AES-256-GCM password or be explicitly created without one after a warning.

No account. No ads. No document upload. The only network feature is a manual update check that runs only when the user taps it in Settings.
